# MEMAR
A Maximum Entropy Model to predict m6A sites. Folders are organized following the sections order of the corresponding paper, to reproduce main and supplementary figures. 
In case of use, please cite:  
A maximum entropy model for m6A prediction: from human transcripts to influenza A viral segments; Ivan Lecce, Pierre-Guillaume Brun, Simona Cocco; bioRxiv 2026.10.26.761909; doi: https://doi.org/10.64898/2026.10.26.761909
